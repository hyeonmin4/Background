# 배경 그라데이션 생성기

두 가지 색상을 선택해 페이지 배경의 좌우 그라데이션을 만들고, 적용된 CSS를 확인할 수 있는 간단한 웹 프로젝트입니다.

## 주요 기능

- 색상 선택기로 그라데이션의 시작 색과 끝 색 지정
- 색상을 변경하면 배경 그라데이션과 CSS 값 즉시 갱신
- 별도의 라이브러리나 빌드 과정 없이 실행

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. `index.html` 파일을 웹 브라우저에서 엽니다.

## 사용 방법

화면의 색상 선택기 두 개에서 원하는 색을 고르면 배경에 좌우 그라데이션이 적용됩니다. 아래 `Current CSS Background` 영역에서 생성된 CSS도 확인할 수 있습니다.

## 프로젝트 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 색상 선택기 |
| `style.css` | 페이지와 텍스트 스타일 |
| `app.js` | 색상 변경 이벤트 처리 및 그라데이션 CSS 갱신 |

## 사용 기술

- HTML
- CSS
